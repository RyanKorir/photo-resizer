# PixelForge — Photo Editor

A powerful, fully browser-based photo editor. No server, no uploads, 100% private.

## Features

- **Adjustments** — Brightness, Contrast, Highlights, Shadows, Saturation, Temperature, Hue, Blur, Vignette, Grayscale, Sepia
- **Filter Presets** — 12 one-click presets (Vivid, Warm, Cool, B&W, Sepia, Fade, Dramatic, Matte, Vintage, Lush, Cinematic)
- **Transform** — Rotate 90°/180°/270°, Flip horizontal/vertical
- **Crop** — Interactive drag handles, rule-of-thirds grid, 7 aspect ratio presets
- **Resize** — Lock aspect ratio, percentage scales, social media presets (Instagram, Twitter, LinkedIn, YouTube)
- **Export** — PNG, JPEG, WebP with quality control
- **Undo/Redo** — 30-step history (Ctrl+Z / Ctrl+Y)
- **Keyboard shortcuts** — +/- zoom, 0 reset view, Ctrl+S export

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + custom CSS variables
- **Image Processing**: HTML5 Canvas API (client-side, zero dependencies)
- **Icons**: Lucide React
- **Deployment**: Vercel

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
